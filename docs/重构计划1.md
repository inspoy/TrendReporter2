## 背景

Tavily的免费额度只有每月5000个url，不太够用

目前大概每次会抓取200条新闻，每月就是200*24*30=144,000条新闻，远远超过免费额度。

Tavily按量付费的价格大概是`0.011 CNY`，如果走DeepSeek，那单条的成本可以压缩在`0.0001 CNY`。

| 项目   | Tavily            | DeepSeek      |
|------|-------------------|---------------|
| 免费额度 | 每月 `5000` 个 `URL` | 无             |
| 单条成本 | `0.011 CNY`       | `0.001 CNY`   |
| 月处理量 | `144,000` 条新闻     | `144,000` 条新闻 |
| 月成本  | `1,584 CNY`       | `144 CNY`     |

## 方案

1. 配置文件中的`tavily`换成`enrichment`
2. 不再强依赖Tavily为唯一的增强服务，改为更通用的`enrichment`，方便未来接入其他增强服务
3. 代码里的接口也要改，`ITavilyClient`应该改为`IEnrichmentClient`
4. V1版本全部实现完之后再做重构

## 一个具体的web_extract服务

我自己搓了一个网页总结服务（底层是调的DeepSeek的API），接口如下

BaseUrl: 在配置文件中配置
EndPoint: `/fetch`
Method: `POST`
Body:
```json
{
    "url": "https://domain.com/some_page_path"
}
```
Return:
成功响应 (200)：
```json
{
    "success": true,
    "message": "ok",
    "url": "https://example.com/article",
    "title": "文章标题",
    "insights": ["要点 1", "要点 2", "要点 3"],
    "summary": "总结内容..."
}
```
错误响应：
```json
{
    "success": false,
    "message": "错误描述"
}
```
HTTP 状态码
- 400 │ 参数缺失或非法 URL
- 502 │ 抓取目标 URL 失败
- 422 │ LLM 返回结果解析失败
- 500 │ 内部错误

配置文件新增：
```yaml
enrichment:
    web_extract_url: "localhost:8080"
```
